Fake Google Meet, for driving the real extension by hand. The DOM below is the same test double the automated fixtures use. This page adds no UI: the Bots button and its panel are the installed content script, so what you are testing is the bundle Chrome runs.

  1. Build a development copy: pnpm dev, or pnpm build:dev for one that does not need the dev server running.
  2. Load it unpacked from build/chrome-mv3-dev on chrome://extensions. Development builds already match localhost, 127.0.0.1 and file://, so there is nothing to edit; published builds match Meet only. Opening this page from disk also needs "Allow access to file URLs" ticking on the extension's card.
  3. Reload this tab after loading the extension. The button appears once the header chip renders, a few seconds in, the way it does on a cold join.
  4. Serving it beats opening it from disk: pnpm play puts it on 127.0.0.1 and opens it for you.

Scenarios: default host | ?bots=20 crowded roster | ?guest=1 not the host | ?bare=1 no toolbar, slow chip. They combine, for instance ?guest=1&bots=20.

In use: no script
